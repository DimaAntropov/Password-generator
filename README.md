# Генератор паролей на Flask

Этот проект — веб-приложение на Flask, которое позволяет пользователю входить в систему, регистрироваться, а также генерировать случайные пароли по заданным параметрам. В приложении реализована простая система авторизации с использованием сессий, и есть возможность создавать уникальные пароли с разными наборами символов.

---

## Возможности проекта

- Регистрация новых пользователей
- Вход и выход из системы
- Генерация случайных паролей по выбранным параметрам:
  - длина пароля
  - использование строчных букв
  - использование заглавных букв
  - использование цифр
  - использование специальных символов
- Защита страниц через декоратор `login_required`

---

## Использование

### Установка

1. Убедитесь, что у вас установлен Python 3.6+.
2. Установите необходимые библиотеки:

```bash
pip install flask
```

### Запуск

1. Склонируйте репозиторий или скачайте файлы.
2. Запустите приложение:

```bash
python app.py
```

3. В браузере перейдите по адресу: [http://127.0.0.1:5000](http://127.0.0.1:5000)

---

## Структура проекта

- `app.py` — основной файл приложения
- `templates/` — папка с HTML-шаблонами:
  - `index.html` — страница генерации паролей
  - `login.html` — страница входа
  - `register.html` — страница регистрации

---

## Как работает

- Пользователь регистрируется, указывая логин и пароль
- После входа в систему можно сгенерировать пароль, выбрав параметры
- Можно выйти из системы и зарегистрировать новых пользователей
