Проект
### 1. `app.db`
- **Тип файла**: база данных SQLite
- **Структура таблиц**:
  - **`users`**:
    - `id`: INTEGER, PRIMARY KEY, AUTOINCREMENT
    - `username`: TEXT, уникальный, не null
    - `password`: TEXT, не null
  - **`service_passwords`**:
    - `id`: INTEGER, PRIMARY KEY, AUTOINCREMENT
    - `user_id`: INTEGER, не null, внешний ключ на `users(id)` с каскадным удалением
    - `service`: TEXT, не null
    - `login`: TEXT
    - `password`: TEXT, не null
    - `created_at`: DATETIME, по умолчанию текущая дата и время
- **Дополнительные сведения**:
  - В таблице `users` есть предзагруженная запись: логин `Танк` и пароль `Железный`.

---

### 2. `init_db.py`
- Функции и скрипты для инициализации базы данных:
  - Создает таблицы `users` и `service_passwords`, если их еще нет.
  - Вставляет в таблицу `users` начальную запись: `Танк` / `Железный`.

---

### 3. `app.py`
- Основной серверный скрипт на Flask:
  - Инициализация приложения, настройка секретного ключа.
  - Функции:
    - `get_db()`: подключение к БД.
    - `login_required()`: декоратор для защиты маршрутов.
    - `generate_password()`: генерация паролей по заданным параметрам.
  - Маршруты:
    - `/` (главная): генератор паролей с настройками, сохраняет пароль и историю сессии, может сохранять пароли в базу.
    - `/passwords`: просмотр сохраненных паролей пользователя.
    - `/login`: аутентификация пользователя.
    - `/logout`: выход из системы.
    - `/register`: регистрация нового пользователя.
  - Перед запуском вызывает `init_db()` для проверки/создания таблиц.

---

### 4. `index.html`
- Веб-страница генератора паролей:
  - Отображает приветствие с именем пользователя и кнопку выхода.
  - Форму выбора длинны пароля и чекбоксов для опций: строчные, прописные, цифры, символы.
  - Кнопка для генерации пароля.
  - Отображение сгенерированного пароля с возможностью его копирования.
  - История сгенерированных паролей с функцией копирования каждого элемента.
  - Анимация фона и стилизация с помощью HTML.

---

### 5. `login.html`
- Веб-страница входа:
  - Поля для логина и пароля.
  - Кнопка входа.
  - Ссылка на регистрацию.
  - Стиль фонового градиента с анимацией.

---

### 6. `register.html`
- Страница регистрации:
  - Поля для логина, пароля и подтверждения пароля.
  - Кнопка регистрации.
  - Ссылка на страницу входа.
  - Анимационный градиент фона, адаптивность по ширине.
