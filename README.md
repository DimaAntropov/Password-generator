# Генератор паролей на Flask

Это веб-приложение, созданное с помощью Flask, которое позволяет пользователю зарегистрироваться, войти в систему, а также сгенерировать случайные пароли по заданным параметрам. Проект служит примером реализации базовой системы аутентификации, генерации паролей и защиты страниц с помощью декораторов.

---

## Возможности проекта

- **Регистрация новых пользователей**: пользователи могут создать учетную запись, указав логин и пароль.
- **Авторизация и выход**: вход в систему и выход из нее с помощью сессий.
- **Генерация случайных паролей**: пользователь выбирает параметры, такие как длина пароля, использование строчных и заглавных букв, цифр и специальных символов.
- **Защита страниц**: доступ к странице генерации паролей только авторизованным пользователям через декоратор `login_required`.
- **Простая система хранения пользователей**: реализована через словарь, что удобно для учебных целей.

## Использование

### Требования

- Python 3.6 или выше

### Установка

1. Склонируйте репозиторий или скачайте файлы проекта.
2. Создайте виртуальное окружение (по желанию):

```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
venv\Scripts\activate     # Windows
```

3. Установите необходимые библиотеки:

```bash
pip install flask
```

### Запуск

1. Запустите приложение командой:

```bash
python app.py
```

2. В браузере откройте страницу по адресу: http://192.168.1.17:5200/login?next=http://192.168.1.17:5200/

## Структура проекта

- `app.py` — основной файл, содержащий маршруты, логику и конфигурацию.
- `templates/` — папка с HTML-шаблонами:
  - `index.html` — страница для генерации паролей (доступна только авторизованным)
  - `login.html` — форма входа
  - `register.html` — форма регистрации

---

## Как работает

1. **Регистрация**:
   - Пользователь переходит на страницу регистрации (`/register`)
   - Указывает логин и пароль, подтверждает пароль
   - Если логин уникален и пароли совпадают, пользователь сохраняется в словаре и автоматически авторизуется
2. **Вход**:
   - Пользователь вводит логин и пароль на странице входа (`/login`)
   - При успешной авторизации попадает на основную страницу
3. **Генерация паролей**:
   - В защищенной области пользователь выбирает параметры генерации
   - После отправки формы появляется сгенерированный пароль
4. **Выход**:
   - Пользователь может выйти, нажав на кнопку "Выйти" (`/logout`), что очистит сессию

## Внесённые изменения и особенности

- **Добавлена регистрация** — реализована через маршрут `/register`.
- **Кнопка регистрации** на странице входа — ведет пользователя на страницу регистрации.
- **Использование словаря `USER_CREDENTIALS`** — подходит только для учебных целей, в продакшене необходимо использовать базы данных.
- **Декоратор `login_required`** — обеспечивает защиту страниц, доступных только авторизованным пользователям.
